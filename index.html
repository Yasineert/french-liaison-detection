Automatic detection of French liaisons in read speech

A phoneme-level system that listens to a learner reading French aloud and tells whether each expected liaison was produced or omitted, with three applications built on top of it: an annotation and analysis platform, a pronunciation trainer, and a model comparison tool.

The problem

In French, a normally silent final consonant is sometimes pronounced when the next word starts with a vowel. This is a liaison. Some are required, some are optional, and some are forbidden. They are hard for children and second-language learners, and checking them by ear does not scale.

  • Liaisons are short, sub-word events: word-level ASR transcripts hide them.
  • The decision depends on context: grammar, word class and register.
  • Learners need precise, immediate feedback on each liaison, not a global score.
Example
les enfants arrivent
/lez‿ɑ̃fɑ̃ a.ʁiv/

The /z/ between les and enfants is a required liaison. If the reader says /le ɑ̃fɑ̃/, the system marks it as omitted.

VL = realised liaisonXL = omitted liaison

Detection pipeline

The system compares what the reader should say with what they actually said, at the level of phonemes.

01

Text

Sentence or paragraph shown to the reader.

02

Reference phonemes

eSpeak NG phonemization plus liaison rules give the expected sequence.

03

Audio → phonemes

A fine-tuned CTC model (WavLM) predicts the phonemes actually spoken.

04

Alignment

Reference and prediction are aligned around each liaison site.

05

Decision

Each liaison is labelled realised (VL) or omitted (XL), with feedback.

Three applications, one stack

The model is used in three tools, each for a different user: researchers, learners and ML engineers.

LiaisonCheck

Annotation and analysis platform: browse the re-annotated corpus, analyse an audio file, inspect each liaison and benchmark models. Includes verified accounts, an activity log and team discussions.

ReactExpressPostgreSQLFFmpeg

Liaison et Moi

Pronunciation trainer: read a sentence, record yourself, get feedback on every liaison and follow your progress over time.

ReactNode.jsWavLMSQLite

Model comparator

Load a short WAV file and compare the phoneme predictions of two fine-tuned checkpoints side by side. Metrics history is stored for reproducibility.

PythonPyTorchTransformers

Architecture

A single Docker Compose stack runs the three applications and a landing page. Each service exposes its own port and shares the Python speech pipeline.
